🐛 COMMON ISSUES
───────────────────────────────────────────────────────────────────────────

Issue: "Redirect URI Mismatch"
Solution: 
   - Verify redirect URI in Google Console matches exactly
   - Wait 5-10 minutes after saving
   - Try in incognito mode

Issue: "Invalid Client"
Solution:
   - Check GOOGLE_CLIENT_ID in .env file
   - Remove any extra spaces or quotes
   - Restart dev server: Ctrl+C, then npm run dev

Issue: User not saved to MongoDB
Solution:
   - Check terminal for "MongoDB connected"
   - Look for error messages in terminal
   - Verify DATABASE_URL in .env

🎯 WHAT HAPPENS DURING GOOGLE SIGN-IN
───────────────────────────────────────────────────────────────────────────

1. Click "Continue with Google"
   → NextAuth redirects to Google OAuth

2. Google Login Screen
   → Enter Gmail credentials
   → Grant permissions

3. Google Callback
   → Returns user data to /api/auth/callback/google

4. App Processes Data (auth.js)
   → Checks if user exists by email
   → Creates new user if needed
   → Generates username from email
   → Saves to MongoDB

5. User is Signed In
   → Session created
   → Redirected to home page
   → User profile appears in navbar
